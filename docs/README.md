# Documentation Index

**Project:** DramaScan — International Drama & Movie Streaming Platform

This directory contains the canonical project documentation, organized by category.
For an overview of the project scope and future upgrades, see `docs/project/project-scope.md`.
For architecture and module boundaries, see `docs/architecture/`.
For requirements, conventions, and development rules, see `docs/development/`.
For approved decisions, see `docs/decisions/`.
For implementation planning and progress tracking, see `docs/implementation/`.
For the future upgrade backlog, see `future/`.

## How to Use This Index

1. **Start here** — Read this `README.md` to understand the documentation structure.
2. **Find the right category** — Use the table above to locate the document relevant to your task.
3. **Read the document** — Each document contains a self-contained overview with links to more detailed specifications.
4. **Check for updates** — Before modifying any feature, read the relevant documents to ensure consistency with approved decisions.
